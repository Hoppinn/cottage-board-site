🎲 코티지 게임 관리

여기서 바꾼 게임 목록·위치는 「사이트에 올리기」를 눌러야 사이트에 반영돼요. 룰 설명·정리 방법은 저장하면 바로 반영돼요.

위치 일괄 변경

게임을 여러 개 골라 한 번에 옮겨요. 「발매후 도착예정·배송중·구매예정」에서 실제 선반으로 옮기면 회원에게 「도착」 알림이 1건으로 묶여 나가요(사이트에 올린 뒤).

새 게임 추가

이름과 위치를 넣고 「목록에 추가」 → BGG에서 같은 게임을 골라요. 후보가 틀리면 BGG 주소를 붙여넣거나 「BGG 없음」을 고르면 돼요.

위치 확인 필요

위치가 비었거나 어느 선반에도 안 맞는 게임이에요. 사이트에서 위치가 「-」로 보여요.

사이트에 올리기

바뀐 게임 데이터를 GitHub에 올려요. 올린 뒤 1~2분이면 사이트에 반영되고, 쌓인 회원 알림도 그때 나가요.
