# Plan — 운영 퍼널 분석 시스템 구축 (Hero + 관리자 분석)

> 저장일: 2026-06-27. 다음 세션 시작 시 검토 후 진행.

## 목표

현재 관리페이지는 **페이지 방문(Page View)** 위주 분석만 제공합니다.

운영상 더 중요한 것은

> **사용자가 어디에서 이탈하는지(퍼널 분석)**

따라서 방문 통계 외에 **행동(Event) 기반 분석**을 추가합니다.

---

## 1. 이벤트 추가

### Hero

| 이벤트 | event_name |
|--------|------------|
| 추천게임 버튼 클릭 | `hero_recommend_click` |
| 플레이기록 버튼 클릭 | `hero_record_click` |

### 추천게임

| 이벤트 | event_name |
|--------|------------|
| 조건 하나 이상 선택 | `recommend_start` |
| 추천 결과 정상 출력 | `recommend_complete` |

### 플레이기록

| 이벤트 | event_name |
|--------|------------|
| 플레이기록 페이지 진입 | `record_start` |
| 플레이기록 작성 완료 | `record_complete` |

### 회원가입

| 이벤트 | event_name |
|--------|------------|
| 회원가입 완료 | `signup_complete` |

---

## 2. Hero 하단 실시간 문구

현재 "오늘 4명 · 누적 501명이 함께했어요." 대체.

```
오늘 X명이 X개의 추천게임을 찾았어요.
오늘 X명이 X개의 플레이기록을 작성했어요.
```

- 사람 수 = unique user
- 게임/기록 수 = 완료 이벤트(`recommend_complete` / `record_complete`) 기준
- 버튼 클릭 수 아님

---

## 3. 관리자 분석 개선

현재 방문자 분석 UI를 **분석 대상 선택형**으로 변경.  
상단에 드롭다운 또는 탭 추가.

```
방문 | 추천게임 | 플레이기록 | 회원가입 | 유입
```

선택 시 동일한 차트 UI 재사용, 내용만 교체.

---

## 4. 방문 분석 (기존 유지)

- 날짜별 방문
- 페이지 방문
- 유입경로
- 페이지 × 유입

---

## 5. 추천게임 분석

### KPI

- Hero 추천게임 클릭
- 추천 시작
- 추천 완료

### 퍼널

```
메인 방문
↓
Hero 추천게임 클릭  (전환율%)
↓
추천 시작          (전환율%)
↓
추천 완료          (전환율%)
```

예시 표시:
```
메인 방문 120 → 추천 클릭 84 (70%) → 추천 시작 72 (86%) → 추천 완료 58 (81%)
```

### 차트

날짜별 추천 완료 수

### 추천 조건 통계 (선택)

가장 많이 선택된 인원 / 난이도 / 게임방식 집계

---

## 6. 플레이기록 분석

### KPI & 퍼널

```
메인 방문 → Hero 기록 클릭 → 기록 페이지 → 기록 완료
```

### 추가 지표

- 사진 첨부 비율
- 게임평 작성 비율 (기존 데이터 활용 가능 시)

---

## 7. 회원가입 분석

퍼널:

```
메인 방문 → 회원가입 시작 → 회원가입 완료 → 첫 추천 완료 → 첫 플레이기록 완료
```

신규 유저 정착률 확인용.
