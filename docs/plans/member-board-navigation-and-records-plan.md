# 회원 보드·플레이 기록·동호회 메뉴 연계 보강 Plan

상태: 1~4순위 코드 수정 및 사용자 브라우저 확인 완료, 프로필 작성/수정 위저드 진입은 사용자 브라우저 확인 완료. 5~6순위 보드 CTA·메인 모임 카드 위치 보정 구현 완료. 위저드는 기록·플래너와 같은 센터모달 규격으로 보정했고 나머지 CTA 사용자 확인 대기
정본: 이 문서
관련 상태: [docs/PROJECT_STATE.md](../PROJECT_STATE.md)

## 세션 계약

- 목표: 내 보드와 다른 사람의 보드에서 게시판 이동 동선을 제공하고, 플레이 기록·동호회 기록의 날짜/모임별 아코디언과 햄버거 메뉴 active 표시를 사용자 의도대로 통일한다.
- 종료 조건: 기존 회귀 버그와 1~8번 요구사항이 화면별로 동작하고, 소유자/타인 권한 차이와 다섯 동호회 URL의 메뉴 상태를 실제 브라우저에서 확인한다. 모임보드의 `코티지 모임 미리보기 페이지 >`는 메인으로 이동하는 것뿐 아니라 메인페이지의 코티지 모임 카드가 화면 최상단에 오도록 진입 위치까지 맞아야 한다.
- 이번 범위: 프로필·모임·수집·기록 보드의 하단/인접 CTA, 플레이 기록 날짜별·모임별 렌더 동작, 동호회 기록 동일 동작, 햄버거 메뉴 active/ancestor 상태, 게임도감 간격.
- 제외 범위: DB 스키마·localStorage·인증 구조 변경, 게시판 자체의 데이터 모델 변경, 사용자가 요청하지 않은 보드 카드 내용 재설계.
- 검증 기준: 각 URL에서 버튼 수·정렬·이동 대상·소유자별 표시 조건, 프로필 작성/수정 위저드의 기존 버튼 진입과 센터모달 규격, 아코디언 자동열림/클릭/상호배타 여부, 메뉴 leaf active와 부모 open 상태, 360px 및 PC 레이아웃을 실제 화면에서 확인한다.

## 요구사항 묶음 및 우선순위

### P1 — 기존 기능 회귀 버그 수정 (#1, #5 일부)

- 프로필보드의 기존 `프로필 수정` 버튼이 눌리지 않는 원인을 먼저 수정한다. 새 게시판 이동 CTA 작업과 분리한다.
- 플레이 기록 페이지의 날짜별 메뉴가 클릭되지 않는 원인을 먼저 수정한다. 아코디언 공통화는 별도 후속 묶음에서 진행한다.

### P1 — 플레이 기록/동호회 기록의 공통 아코디언 동작 (#5, #8)

- 플레이 기록 페이지의 날짜별 메뉴가 클릭되지 않는 원인을 확인한다.
- 플레이 기록 미리보기에서 이미 동작하는 자동열림·아코디언·기록 더보기 렌더 경로를 본 페이지의 날짜별/모임별 보기에도 재사용한다.
- 동호회 `club-history.html`에도 같은 자동열림·아코디언 동작을 적용한다.
- 공유 renderer/helper가 있으면 재사용하고, 없으면 동작 계약이 같은 최소 공용 경로를 만든다.

### P1 — 햄버거 메뉴 페이지 active/ancestor 상태 (#7)

- 현재 페이지의 leaf만 진한 active 박스로 표시하고, 동호회 하위 페이지는 부모를 자동으로 펼친다.
- 동호회 메뉴에 없는 `club-rules.html`은 leaf active 없이 부모 open만 유지한다.
- 최근 동호회 메뉴 CSS 수정 커밋과 실제 DOM/class/cascade를 다시 대조해 점 표시와 박스 표시가 섞이지 않게 한다.

### P2 — 보드 간 게시판 이동 CTA 및 소유자 조건 (#1 일부, #2, #4, #6)

- 프로필보드: 현재 프로필이 없으면 `프로필 작성`, 있으면 `프로필 수정`이 프로필 페이지 본문을 표시하지 않고 기존 위저드 버튼을 직접 실행하며, `모임원 프로필 페이지 >`는 전체 페이지로 이동한다.
- 모임보드: 하단에 `코티지 모임 미리보기 페이지 >`를 두고 메인 진입 시 코티지 모임 카드가 최상단에 오도록 연결한다.
- 기록보드: `기록 작성`은 보드 위 센터모달에서 기록 입력 탭을 직접 열고, `플레이 기록 페이지 >`는 전체 페이지로 이동한다.
- 내 보드와 타인 보드 모두 게시판 이동 버튼을 제공하되, 타인 보드에는 수정/등록 액션을 노출하지 않는다.
- 기존 인증·저장 동작과 전체 페이지 이동 링크는 보존한다.

### P3 — 게임도감 밀도 조정 (#3)

- 수집보드의 게임도감 항목별 줄바꿈 공간을 현재의 약 1/3 수준으로 줄인다.
- 데이터/정렬/상호작용은 바꾸지 않고 해당 목록의 간격만 조정한다.

## 최종 작업 순서

1. 기존 기능 버그 수정: 프로필보드의 `프로필 수정` 버튼 회귀를 조사·수정한다.
2. 기존 기능 버그 수정: 플레이 기록 페이지의 날짜별 메뉴 클릭 불능을 조사·수정한다.
3. 햄버거 메뉴의 active 링크 계산, ancestor open, CSS cascade를 동호회 다섯 URL에서 재검증하고 수정한다.
4. 플레이 기록 날짜별·모임별과 `club-history.html`의 자동열림·아코디언 동작을 공통 패턴으로 정리한다.
5. 프로필·모임·기록 보드의 하단 게시판 이동 CTA와 본인/타회원 권한 표시를 공통 패턴으로 정리한다.
6. 모임 미리보기 링크가 메인페이지의 코티지 모임 카드를 화면 최상단에 두는 진입 위치까지 맞는지 검증하고, 기록 작성/플레이 기록 이동도 검증한다.
7. 게임도감 간격을 조정하고 360px/PC에서 밀도와 줄바꿈을 확인한다.

## 조사·변경 계획

읽을 파일: `docs/PROJECT_STRUCTURE.md`, `docs/DESIGN_RULES.md`, `docs/js-api.md`, `assets/js/header.js`, `assets/js/script-nav.js`, 플레이 기록/보드 관련 페이지와 renderer 파일

변경할 대상: 기존 플레이 기록 미리보기의 자동열림·아코디언 renderer/event path → 본 페이지와 동호회 기록의 동일 계약으로 재사용; 기존 보드 CTA renderer → 내/타인 소유권 조건을 유지한 게시판 이동 CTA 추가; 기존 햄버거 active 계산/CSS → leaf active와 ancestor open 분리

새로 생성: 원칙적으로 없음. 기존 renderer/helper를 확장한다. 공통 경로가 없고 중복을 피할 수 없을 때만 새 helper를 제안한다.

영향 파일: 조사 후 확정. 예상 범위는 `assets/js/`의 보드·플레이 기록 관련 JS, `pages/club/club-history.html`, 플레이 기록/보드 HTML, `assets/css/style.css`, 필요 시 `assets/js/header.js`·`assets/js/script-nav.js`.

보존해야 할 기존 동작: 내 보드의 수정/등록 액션, 타인 보드의 읽기 전용 상태, 플레이 기록의 자동열림 기준과 모임별/날짜별 데이터, 동호회 기록의 기존 기록·사진·DB 연동, 기존 메뉴의 다른 그룹 active 및 desktop hover.

위험요소: 미리보기와 본 페이지가 서로 다른 renderer를 사용하면 수정이 한쪽에만 반영될 수 있음; 타인 보드에서 소유권 조건을 잘못 적용하면 수정/등록 버튼이 노출될 수 있음; 메인 scroll anchor가 sticky header 보정을 중복 적용할 수 있음; 메뉴 fallback이 여러 leaf를 활성화할 수 있음; 좁은 화면에서 CTA가 줄바꿈될 수 있음.

롤백 방법: 기능 묶음별 커밋으로 분리하고 해당 커밋만 되돌린다. DB·사용자 데이터 변경은 하지 않는다.

## 검증 체크리스트

- 플레이 기록: 날짜별 메뉴 클릭, 모임별 메뉴 클릭, 미리보기와 동일한 자동열림, 기록 더보기, 다른 그룹을 열 때 기존 그룹 닫힘 여부.
- 동호회 기록: 자동열림, 날짜/모임 아코디언, 기록 더보기, 기존 사진/기록 이동 보존.
- 보드 CTA: 내 보드/타인 보드 각각 프로필·모임·기록 CTA 수와 소유자별 수정/등록 노출 여부, 내 보드에서 프로필 작성/수정 위저드·기록 입력 모달이 직접 열리는지.
- 메인 이동: `코티지 모임 미리보기 페이지 >` 클릭 후 메인에서 해당 카드가 최상단에 위치.
- 햄버거: `club.html`, `club-schedule.html`, `club-intro.html`, `club-history.html`, `club-rules.html` 각각 leaf active 수와 부모 open 수를 확인.
- 반응형: 360px 및 PC에서 버튼 2개 가로 정렬, 메뉴 indentation, 도감 간격, 기록 아코디언을 확인.
