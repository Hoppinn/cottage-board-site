# 동호회 중첩 메뉴 시각 위계 수정 Plan

상태: 구현 완료 — 브라우저 실화면 확인 대기

## 목표

동호회를 `코티지 이용` 안의 2차 메뉴로 보이게 하고, 실제 이동 링크만 3차 메뉴로 들여쓴다. 현재 중첩 메뉴의 열림·활성화·스크롤 추적 로직은 유지한다.

## 시각 계약

- `동호회`는 가격·이용안내, 홈페이지 기능, 요청하기와 같은 2차 레벨이다. 폰트 크기·좌측 시작 위치·세로 padding·기본 색상을 맞추고 테두리·둥근 박스·강한 버튼 배경을 쓰지 않는다.
- 동호회에는 하위 항목이 있음을 알리는 작은 chevron만 둔다. 자식 leaf가 활성화됐을 때도 부모는 펼쳐진 상태와 약한 강조만 보인다.
- 네 leaf는 2차 메뉴보다 한 단계 더 들여쓰며, 필요한 범위에서 더 작은 글자 또는 약한 색으로 구분한다. 기존 leaf 활성 및 메인 스크롤 점 표시는 유지한다.
- 데스크톱에서는 동호회 popup이 2차 행의 오른쪽에서 열리고, 모바일에서는 같은 들여쓰기 관계가 유지돼야 한다.

## 구현 범위

읽을 파일: `assets/css/style.css`, `assets/js/header.js`, `assets/js/script-nav.js`, `docs/PROJECT_STATE.md`

변경할 대상: `menu-group--nested`의 CSS만 2차 메뉴 레벨에 맞춘다. JS의 중첩 아코디언·조상 그룹 열기·현재 leaf 활성·scroll-spy는 변경하지 않는다.

새로 생성: 이 Plan 문서

영향 파일: `assets/css/style.css`, `docs/PROJECT_STATE.md`

보존할 기존 동작: 2단 중첩 아코디언, 정확한 leaf 활성, 부모 자동 열림, 메인 `#meeting`의 모임 플래너 점, 기존 1단 게임/코티지 이용 메뉴

위험요소: 모바일에서 2차/3차 들여쓰기가 과도해지는 문제, 데스크톱 중첩 popup의 기준 위치 변경

검증: 360px에서 2차 동호회와 3차 leaf의 시작 위치·padding·색상을 비교하고, 720px 이상에서 동호회 hover popup 위치와 leaf 활성 상태를 확인한다.

## 진행 기록

- 2026-09-01: 중첩 아코디언·활성화·scroll-spy JS는 변경하지 않고 CSS만 조정했다. 동호회는 2차 링크와 같은 padding·글자 크기·기본 색을 쓰며, leaf만 한 단계 더 들여쓰고 약한 글자 톤을 쓴다. 활성 leaf는 기존 active 색을 유지하도록 비활성 leaf에만 약한 색을 적용했다.
