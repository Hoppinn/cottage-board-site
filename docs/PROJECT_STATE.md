- **이번 범위:** ① 닉네임 클릭 회귀 수정 ② 프로필에 실제 게임 경험 최대 2개와 승인된 평소 역량 정보 저장·표시 ③ 플래너 Step 4를 「오늘 느낌」으로 명확히 묶기 ④ 참여자 카드에 평소 핵심 정보와 오늘 정보를 compact하게 분리 표시.
- **제외 범위:** 자동 매칭·후보 제안·점수화, 기존 쿠폰 정책, 기존 일정·게임 선택·동반 인원 로직, 평소 정보와 날짜별 정보를 한 저장소에 합치는 변경.
- **현재 구조 실측:** `member_intros`에는 평소 선호 유형·참여 가능 시간·빈도 등이 있으나 게임 스타일/깊이 및 「가장 어려웠던 게임」 전용 필드는 없다. `meeting_votes`의 `game_style`·`game_style_custom`·`game_depth`·`play_traits`·`recruitment_message`와 `meeting_vote_games.want/learn`은 이미 날짜별 오늘 정보로 분리돼 있으며 등록 UI는 시간 다음에 오늘 원하는 판, 그 다음 선택 게임을 받는다. `meeting_game_prefs.can_explain_rules`는 상시 룰 설명 가능 게임 목록으로 현역이다.
- **승인된 정보 구분:** 평소 취향=`preferred_game_types`+즐기는 깊이, 실제 경험 수준=해본 게임 중 가장 어려웠던 게임 최대 2개, 룰마 역량=`meeting_game_prefs.can_explain_rules`, 관심=`game_curious`, 오늘 실제 플레이 의지=`meeting_vote_games.want/learn`, 고난도 학습 의지=날짜별 성향 「모르는 어려운 게임도 배워볼게요」. `익숙함`·`초보/중급/고수` 같은 모호한 자기평가는 만들지 않는다. 카드에서는 `평소`/`오늘`을 나누고 경험 게임은 `경험:` 라벨로 표시한다.
