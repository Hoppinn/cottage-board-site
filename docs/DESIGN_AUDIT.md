## 3. 전체 페이지 타이포+여백 개선 (남은 핵심 작업)

> GPT 분석 인용: "예쁜 사이트들이랑 차이나는 이유 70%는 색상이 아니라 여백. 같은 내용이어도 숨 쉴 공간이 더 많아 보임."

현재까지 owned-games 일부만 개선됨. 전 페이지 체계적 적용이 아직 미완.

### 개선 방향

- **꽉 찬 느낌 해소**: 카드↔카드 간격, 섹션↔섹션 간격 소폭 증가
- **타이포 계층 강화**: 섹션 제목 / 본문 / 보조 텍스트 구분이 현재 약함
- **line-height**: 본문 텍스트 줄간격이 전반적으로 빡빡한 경향

### 페이지별 확인 포인트

| 페이지 | 확인 항목 |
|--------|----------|
| index.html | 섹션 헤더 여백, 추천 섹션 상단 여백 (12→22px 이전에 revert됐음, 재검토) |
| game-reviews.html | 탭 버튼 높이/padding, 색상 수정 후 여백 확인 |
| about.html | ABOUT 본문 줄간격, 섹션 간격 |
| price-rules.html | "이런 것도 돼요" 그리드 여백, 규칙 항목 줄간격 |
| club.html | 본문 텍스트 줄간격 |

| club-rules.html | 규칙 항목 줄간격 |

### 작업 기준

- 색상 및 컬러 변경 없음
- padding/margin/line-height/font-size 조정만
- 한 번에 큰 리디자인 금지 — 페이지별 소폭 개선

## 4. 색상 통일/변주 판단 (플레이 기록 헤더)

### 현재 문제

플레이 기록 전체에 `#2c3e50` (Material Blue Grey 800) 계열 사용:
- `.pr-session > .pr-session-hd` (그룹 헤더 배경)
- `.history-group-header` (모임 기록 그룹 헤더)
- `.pr-sub-date` (날짜 텍스트 색)
- `.pr-tag-count`, `.pr-tag-count-game` (태그 배경)
- `.pr-tag-who-first` (밑줄 색)
- `.pr-rec-review` (후기 좌측 바 색)

### 색상 옵션 분석

| 옵션 | 색상 | 장단점 |
|------|------|--------|
| A. 순수 갈색 전환 | `#3d2010` | 브랜드 일치하지만 전체가 갈색이라 피곤함 |
| B. 딥 포레스트 그린 | `#2d4a3e` | 자연/숲 계열 — 갈색 변주 제공, 보드게임 카페 느낌 유지 ★추천 |
| C. 다크 올리브 | `#3d4a2e` | B보다 덜 진함, 덜 뚜렷한 차이 |
| D. 유지 (블루그레이) | `#2c3e50` | 현재 상태, 이질적으로 보임 |

### 결정: 딥 포레스트 그린 `#2d4a3e` 채택

**이유:**
1. 갈색 + 포레스트 그린 조합은 자연/카페/보드게임 분위기와 잘 어울림
2. 어두운 배경이 필요한 그룹 헤더에 충분한 대비 (흰 텍스트 가독성 확보)
3. 전면 갈색보다 눈이 덜 피로함 — 사용자 요청에 부합
4. 기존 블루그레이보다 팔레트 정합성 높음

### 계층별 색상 설계

```
1단계 (그룹 헤더) : #2d4a3e  ← 딥 포레스트 그린, 흰 텍스트
2단계 (날짜 행)   : #5a3a1a  ← 중간 갈색 텍스트, 배경 없음
3단계 (게임 레코드): #fff    ← 흰 배경 (현재 유지)
```
