# 게임 관리 프로그램 사용법

게임 추가·위치 변경·룰 설명·정리 방법을 명령어 없이 한 화면에서 합니다.

## 처음 한 번만: 바탕화면 아이콘 만들기

1. 바탕화면 빈 곳 우클릭 → **새로 만들기 → 바로 가기**
2. 항목 위치에 아래를 그대로 붙여넣기 → 다음
   ```
   wsl.exe -d Ubuntu --cd ~/cottage-board-site -- npm run admin
   ```
3. 이름: `코티지 게임 관리` → 마침

더블클릭하면 검은 창이 하나 뜨고 브라우저에 관리 화면이 열립니다. **검은 창을 닫으면 프로그램이 꺼져요.** 이미 켜져 있을 때 또 누르면 브라우저 화면만 다시 열립니다.

> 우분투 이름이 `Ubuntu`가 아니면 PowerShell에서 `wsl -l`로 이름을 확인해 `-d` 뒤에 넣으세요.

## 탭별로 하는 일

| 탭 | 할 수 있는 것 | 사이트 반영 |
|---|---|---|
| 위치 일괄 변경 | 여러 게임을 골라 한 번에 다른 선반으로. 기본은 「발매후 도착예정」 목록 | 「사이트에 올리기」 후 |
| 새 게임 | 이름·위치 → 목록에 추가 → BGG 후보 클릭(또는 주소 붙여넣기 / BGG 없음) | 「사이트에 올리기」 후 |
| 게임 수정 | 위치, BGG 다시 연결, 룰 설명 4칸, 자주 틀리는 규칙, 정리 방법(글·사진) | 위치·BGG는 올린 후, **룰·정리 방법은 저장 즉시** |
| 위치 확인 필요 | 위치가 비었거나 잘못 적힌 게임을 바로 고침 | 「사이트에 올리기」 후 |
| 사이트에 올리기 | 바뀐 것과 보낼 알림을 확인하고 버튼 하나로 올림 | 1~2분 뒤 |

## 회원 알림(종 모양)

- 새 게임을 추가하거나, 「발매후 도착예정·배송중·구매예정」에서 실제 선반으로 옮기면 알림이 **쌓입니다.**
- 알림은 **「사이트에 올리기」가 성공한 뒤에만** 나갑니다. 사이트엔 아직 「도착예정」인데 「도착!」 알림부터 가는 일을 막기 위해서예요.
- 여러 게임을 한 번에 옮기면 알림도 1건으로 묶입니다. 알림이 필요 없으면 저장 전에 「회원에게 알림 보내기」 체크를 끄세요.

## 안 될 때

| 메시지 | 할 일 |
|---|---|
| 엑셀 파일이 열려 있어요 | Excel에서 `cottage-owned-games.xlsx`를 닫고 다시 |
| main 브랜치가 아니라서 올릴 수 없어요 | 다른 작업 중인 브랜치예요. 그 작업을 마치거나 `git switch main` 후 다시 |
| GitHub에 더 새 버전이 있어요 | 터미널에서 `cd ~/cottage-board-site && git pull` 후 다시 |
| GitHub에 올리지 못했어요 | 인증 문제일 가능성이 커요. 커밋은 PC에 남아 있으니 인증을 고친 뒤 `git push` |
| 설명 번역 ⏸️ 번역 대기 | `.env`에 `ANTHROPIC_API_KEY`가 없어서예요. 키를 넣고 그 게임을 다시 연결하면 번역돼요 |
| BGG 정보 받기 ❌ (401) | `.env`에 `BGG_API_TOKEN`이 없거나 만료. 「BGG 없음」으로 추가해 두고 나중에 다시 연결 가능 |

필요한 키(`.env`, 이 폴더 맨 위):
```
ANTHROPIC_API_KEY=...
BGG_API_TOKEN=...
```
